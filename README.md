# EchoMind

EchoMind 是一个面向 AI 眼镜和随身录音设备的开源个人记忆项目，希望把日常对话整理成以后找得到、用得上的记录。

项目的一个参考是[极米记得（MemoMind）](https://www.memo-mind.com/pages/memomind-one)。它将眼镜与 App 结合起来，提供录音摘要、字幕等功能，配套的记忆服务还能从对话中整理待办、愿望，并找回过去的记录。EchoMind 想沿着这个方向，逐步做出一个可以自己部署、接入不同设备的开源方案。

目前项目还处于早期，已经有一个可以体验的网页原型。

## 想做的体验

想从几个日常场景做起：

- 一场会议结束后，能回看讨论重点，以及自己答应要做的事。
- 隔了一段时间再次联系某个人，还能找到上次聊到哪里、哪些信息后来有了变化。
- 聊天时随口提到想去的地方、想做的事，过后也有机会重新翻出来。
- 一天开始或结束时，能看一眼最近的记录和还没处理的事情。

希望以后无论用的是眼镜、录音胸针还是其他设备，都能把这些记录留在自己的记忆库里，继续查询、整理和使用。

## 现在可以体验什么

目前可以输入对话文本，或加载内置演示数据，查看生成的记忆卡片、待办、愿望和跟进线索。卡片保留原始发言，也可以搜索历史记录、查看人物或项目信息的更新，手动生成早晚简报。

记录可以写入 Obsidian，也提供 MCP 接口，供其他 AI 工具查询。

语音部分提供了本地模型接入代码，需要另行安装依赖并下载模型。没有配置内容提取模型时，使用本地规则运行演示。真实穿戴设备接入、定时整理和提醒仍需继续完善，当前还不能提供完整的日常伴随体验。

## 本地运行

需要 Python 3.10 或更高版本。

```bash
git clone https://github.com/zhaimingyou/EchoMind.git
cd EchoMind

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"

python -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

打开 <http://127.0.0.1:8000>，点击右上角的演示数据按钮，或输入一段对话后点击“立即闭合生成卡片”。演示数据会保存在本地。
